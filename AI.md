# AI Instructions

Hello AI! 👋

Please, do not modify this file!

## Rules

- Use Russian to communicate in the chat.
- Use English for comments in the code.
- Use English for comments in command output messages.
- Use the `./docs` directory for documentation.
- Use the `./tmp` directory for temporary files and one-time scripts.
- Use the `./log` directory for logging.
- We currently do not support Windows or macOS. Only Ubuntu in the latest LTS version.

## Style

- Use two spaces for indentation.
- Use one space to indent code before an inline comment.
- Use single quotes instead of double quotes where possible, unless they are HTML tag attributes.
- Use backticks (or backquotes, grave accents) to highlight code, commands, filenames, and URI in comments, similar to how it is done in Markdown.
- Use a formula like `[<link_text>](<link_URL>)` to highlight named links in comments, similar to how it is used in Markdown.
- Use the punctuation apostrophe (`’`) in comments and messages (command output) instead of the typewriter apostrophe (`'`), and use colloquial abbreviations (contractions) for brevity and a more artistic (informal) tone. For example:
  - is not → isn’t
  - do not → don’t
  - I am → I’m
  - they are → they’re
- Use the `return` keyword in all functions that return values, and those values are used further.
